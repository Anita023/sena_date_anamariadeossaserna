#sena_date_anamariadeossaserna

Una utilidadpara manejar fechas en formato timestamp y long

## Install 

``` bash
npm install sena_date_anamariadeossaserna
```

## Uso 

``` js 
const {getTimeStamp, getLongTime} = require('sena_date_anamariadeossaserna')

getTimeStamp(); 
getLongTime('en-US');

```
